# Contributing

Thanks for helping build OpenGEO.

1. Fork and clone the repository.
2. Install Node.js 20 or later.
3. Run 'npm test' and 'npm run check'.
4. Open a focused pull request with tests and a clear explanation.
5. For new audit rules, document evidence, severity, and false-positive limitations.
6. Never claim a heuristic score predicts citations or ranking.

Security-related findings should be reported privately; see SECURITY.md.

Code style: simple native ESM, descriptive functions, minimal dependencies, and no arbitrary remote-code execution. Do not paste private API tokens into fixtures.
